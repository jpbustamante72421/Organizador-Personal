NOMBRE DEL PROYECTO

Organizador Personal

OBJETIVO DEL PROYECTO:

La intención es preparar la estructura inicial
de una aplicación que, en el futuro, podría administrar tareas y notas. Con esto sería más fácil poder administrar las tareas personales.

TECNOLOGIAS UTILIZADAS:

Python: Lenguaje de programación utilizado para desarrollar la aplicación.

Requests: Librería de python

python-dotenvython: Librería de python

Visual Studio Code: Entorno de desarrollo utilizado para escribir y ejecutar el código.

Git y GitHub: Herramientas para administrar versiones y respaldar el proyecto.

PASOS DE INSTALACIÓN:

Descargar e instalar Python desde su página oficial.

Descargar e instalar Visual Studio Code.

Instalar Git para administrar las versiones del proyecto.

Crear o descargar el proyecto desde GitHub.

Abrir la carpeta del proyecto en Visual Studio Code.

Abrir la terminal y ejecutar los siguientes comandos para instalar las librerías:

pip install requests python-dotenv

Crear un archivo .env para guardar las variables de configuración necesarias.

Ejecutar el archivo principal de Python para comprobar el funcionamiento de la aplicación.

DEPENDENCIAS:

Python: Ejecutar el código de la aplicación.
Requests:Realizar solicitudes a APIs y servicios externos.
python-dotenv:Gestionar variables de entorno mediante un archivo .env.
Git:Controlar las versiones del código.
GitHub:Almacenar y respaldar el proyecto en línea.
