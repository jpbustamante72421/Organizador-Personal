Registrar tareas: Permitir al usuario agregar nuevas tareas y 
actividades pendientes.

Consultar tareas: Mostrar las tareas registradas para facilitar su 
organización y seguimiento.

Modificar tareas: Permitir editar la información de las tareas 
existentes.

Marcar tareas como terminadas: Indicar cuándo una tarea ha sido 
completada.

Registrar notas: Guardar información, ideas o apuntes personales y 
académicos dentro de la aplicación.
